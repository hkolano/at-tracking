## Project Overview
This is a forked version of https://github.com/connorbrooks18/at-tracking. The goal of this version is to track the bending of blueberry canes over time with April Tags by returning to the same blueberry bushes multiple times over the course of a season. 

## Always do
Write a docstring at the beginning of each function. 

## Directory structure
Python files that are part of the pipeline can go in /src. Temporary test files that will not be part of the overall pipeline can go in /utils. Generated data such as .parquet files, .csv files, and recordings can be saved under /data.
